## 1. Project overview

Fisher Game is a low-poly 3D fishing game set in a small archipelago. This document defines **everything about the fish**: the 122 species, their rarity, where they live, what they are worth, how big they get, the mutation layer and the five fishing rod tiers. It is meant to be complete enough to implement fishing without inventing missing data.

| Item | Count |
|---|---|
| Fish species | **122** |
| Rarities | **6** (Common 36, Uncommon 30, Rare 24, Epic 16, Legendary 10, Mythical 6) |
| Fishing zones | **12** (8 regular, 4 hidden/special) |
| Fishing rod tiers | **5** (gameplay stats only, models are made by the team) |
| Mutations | **10** (separate layer on top of rarity) |

**The world.** The game has the four main islands plus Teun's quest island (see `QUESTLINE.md`):

| Island | Role | Fishing zones around it |
|---|---|---|
| Home Island | Player's home | Home Lagoon |
| Fish Selling Island | Ruben buys fish in the lighthouse | Harbor Waters (harbour), Lighthouse Point (cliffs) |
| Boat Dealer Island | Emre sells boats | Harbor Waters (marina), Sunlit Reefs |
| Fishing Rod Shop Island | Mark sells rods and the rod upgrades below | Kelp Rocks |
| Teun's Rock (Cave Island) | Quest hub | Kelp Rocks (coast), Teun's Grotto (cave pool) |
| Open sea | – | Open Ocean (centre), The Drop (outer ring), 4 hidden zones at the map corners |

**Restrictions respected.** The existing wave code (`WaterManagement`, `WaterManager`, `Floater`) is untouched and no new water system is introduced. No boat models or boat systems are created (boats are made by another developer). No fishing-rod models are created; rods are documented as gameplay data only.

### Spawn chance guidelines

Each zone has a list of fish. A bite picks one fish from that list, weighted by its **spawn weight** (rarity weight × species abundance, ×1.5 in the fish's preferred zone, × the rod's rarity bonus for Rare and above). Because zones contain different mixes, the real chance differs per zone; section 6 lists all of them. Typical share of a bite in a mixed zone (Open Ocean):

| Rarity | Starter Rod | Reefrunner Rod | Leviathan Rod |
|---|---|---|---|
| Common | 64.1% | 62.4% | 59.6% |
| Uncommon | 25.2% | 24.5% | 23.4% |
| Rare | 8.40% | 10.2% | 13.3% |
| Epic | 1.95% | 2.37% | 3.08% |
| Legendary | 0.38% | 0.46% | 0.60% |
| Mythical | 0.01% | 0.01% | 0.02% |

### Mutations (separate layer)

Mutations are **not** a rarity. After a fish is chosen, a mutation is rolled independently, so a Common Sand Goby can be Celestial and a Mythical Quackfin can be Golden. A fish has at most one mutation. Mutations change the existing model through materials (and a few small geometry add-ons); there are no separate mutation species.

| Mutation | Chance | Value × | Condition | Appearance | Special |
|---|---|---|---|---|---|
| **Albino** | 1 in 250 | ×2 | Any zone, any time. | Body and fins pure white to pale pink, eyes red. Pattern faintly visible. | Size/weight unchanged. First mutation most players see. |
| **Shadow** | 1 in 400 | ×2.5 | Night only. | Near-black body with deep purple fins; eyes glow faint violet. | Only rolls at night. Slightly faster fight (+5 difficulty). |
| **Glowing** | 1 in 350 | ×3 | Night, or any time in The Drop / Serpent's Abyss. | Pattern and fin edges glow cyan; the fish lights up the water around it. | Visible from the boat at night (small point light in Unity). |
| **Golden** | 1 in 600 | ×5 | Any zone, any time. | Polished gold body, brighter gold fins, metallic shine. | Weight +10% (gold is heavy). Classic collector mutation. |
| **Radioactive** | 1 in 1,500 | ×4 | After a storm, any zone. | Toxic green body with glowing yellow-green blotches. | Cannot be eaten in future cooking systems; worth more to collectors. |
| **Crystal** | 1 in 1,200 | ×6 | Any zone; 5x more likely in Teun's Grotto. | Translucent ice-blue body with faceted crystal shards growing from the back. | Weight +30%. Shards make it instantly recognisable. |
| **Ancient** | 1 in 2,000 | ×8 | Shipwreck Graveyard and The Drop only. | Bronze/stone coloured body covered in bony plates, like a living fossil. | Size +25%, weight +40%. Heaviest possible version of any species. |
| **Ghost** | 1 in 3,000 | ×7 | Night, Shipwreck Graveyard 4x more likely. | Pale, see-through body; only the skeleton line and eyes are solid. | Weight -50% (barely there). |
| **Rainbow** | 1 in 5,000 | ×12 | Any zone during or right after rain. | Every band of the fish a different colour of the rainbow, shimmering. | Cannot combine with other mutations (it replaces them). |
| **Celestial** | 1 in 20,000 | ×25 | Clear night only; 3x more likely in Serpent's Abyss. | Deep night-blue body sprinkled with glowing stars; fins fade into a nebula purple. | Rarest mutation. Shows a star trail when reeled in. |

**Roll order.** Mutations are checked from rarest (Celestial) to most common (Albino); the first success wins. Each chance is multiplied by `1 + luck/100` of the rod and only rolls when its condition is met. Rainbow replaces any other mutation. The Crystal Sovereign cannot become Crystal.

**Model modification per mutation:**

- **Albino**: Swap every body/fin material for M_Mut_Albino (white, slightly pink fins); eye material -> red.
- **Shadow**: Body/fins -> M_Mut_Shadow (black, purple fins), eyes -> emissive violet.
- **Glowing**: Pattern/accent materials -> emissive cyan M_Mut_Glow; add a small point light (range ~2x fish length).
- **Golden**: All body/fin materials -> M_Mut_Golden (metallic 1.0, roughness 0.25).
- **Radioactive**: Body -> M_Mut_Radioactive (green), pattern faces -> emissive lime; optional faint green particles.
- **Crystal**: Body -> transparent M_Mut_Crystal; add 3-6 crystal shard cones along the dorsal line (as in the preview).
- **Ancient**: Body -> M_Mut_Ancient (bronze stone); add bony plate boxes on the back; scale model by 1.25.
- **Ghost**: Body/fins -> transparent M_Mut_Ghost (alpha ~0.35); keep eyes opaque.
- **Rainbow**: Assign rainbow materials per pattern band/fin (red-orange-yellow-green-blue-violet).
- **Celestial**: Body -> M_Mut_Celestial (dark blue) + emissive star dots; fins -> purple gradient.

A preview of every mutation applied to the same fish is in `Fish.blend` (collection `Mutation_Preview`).

**How the stats work**

- **Fishing power** vs. fish **difficulty**: a fish can be hooked when `difficulty ≤ power + 8`. If the difficulty is above the power, the reel minigame gets harder (faster fish, smaller catch zone) by `(difficulty − power) × 4%`. Above `power + 8` the line always snaps.
- **Rarity bonus** multiplies the spawn weight of Rare, Epic, Legendary and Mythical fish.
- **Luck** multiplies every mutation chance by `1 + luck/100` and adds `luck/2` % to the chance of the bigger half of a fish's size range.
- The Starter Rod (power 25) lands every Common fish and the lighter Uncommon fish. The Leviathan Rod (power 92) can hook everything, but Mythical fish (difficulty 86–98) still fight above its power, so the challenge remains.

## 7. Fish economy and selling values

**Base value** of a species = `12 × rarity multiplier × species factor` (species factor 0.8–1.3; heavier species in a rarity are worth a bit more). Ruben (Fish Selling Island) pays:

```
price = round(base_value × size_multiplier × mutation_multiplier)
size_multiplier = clamp((weight / average_weight) ^ 0.6, 0.6, 1.8)
```

| Rarity | Multiplier | Lowest base value | Highest base value | Avg. base value |
|---|---|---|---|---|
| Common | ×1 | 10 | 14 | 12 |
| Uncommon | ×3 | 29 | 47 | 37 |
| Rare | ×8 | 77 | 115 | 96 |
| Epic | ×25 | 240 | 360 | 300 |
| Legendary | ×80 | 768 | 1200 | 1003 |
| Mythical | ×250 | 2400 | 3600 | 3000 |

### Size and weight

Every catch gets its own size and weight inside the species range:

```
t      = (rand() + rand()) / 2            # bell curve, most fish are average
t      = t ^ (1 - luck/200)                 # luck nudges toward bigger fish
length = lerp(min_length, max_length, t)
k      = (length^3 - min_length^3) / (max_length^3 - min_length^3)
weight = lerp(min_weight, max_weight, k) × random(0.92, 1.08)   # clamp to the weight range
```

Weight follows the cube of length, so a longer fish is (almost) always heavier. The model is scaled by `length / average_length`. Average values in the catalog use the same formula at `t = 0.5`.

### Mutations and value

Mutation multipliers stack with size, not with each other (one mutation per fish). Some mutations also change size or weight (Golden +10%% weight, Crystal +30%% weight, Ancient +25%% length/+40%% weight, Ghost −50%% weight), applied after the roll.

**Example – Golden Atlantic Bluefin Tuna:** Legendary, base value 939. Caught at 260 cm, 380 kg → Golden adds 10% weight → 418 kg. Average weight is 282 kg, size multiplier = 1.27. Price = 939 × 1.27 × 5 = **5,944 coins**.

## 8. Model creation guidelines

All 122 fish models exist and are generated by `Scripts/fish_models.py` from the same data as this document.

- **Style:** low poly, flat shaded, solid colours (no textures), matching the islands. Budget: ~80–700 vertices per fish (average ~200, all 122 together ~24,500 vertices).
- **Shapes:** 27 body plans (torpedo, deep, flat, eel, ray, shark, angler, seahorse, mola, ...), 18 tail types, 30+ dorsal fin types and 40 signature details (bills, lures, horns, barbels, photophores, crystals, ...). Colour is never the only difference.
- **Scale:** each model is built at the species' **average length** in metres. Scale at runtime by `length / average_length`.
- **Orientation:** the head points to Blender **-Y**, which is Unity's **+Z (forward)** with the project's FBX export settings; up is Blender +Z / Unity +Y. Origin = centre of the body.
- **Materials:** shared colour materials named `M_Fish_<hex>`, eyes `M_FishEye`/`M_FishPupil`, glow `M_FishGlow_<hex>`. Mutations replace the colour materials (see section 2) and never the eye materials.
- **Files:** `Blender/Models/Fish.blend` (collections per rarity, a normalised catalogue sheet and the mutation preview) and `Export/Fish/Fish_###_Name.fbx` (one per fish, at the origin).
- **Rods and boats:** not modelled here on purpose.

Each fish's individual model description is part of its catalog entry in section 5.

## 9. Technical implementation notes

**Data.** Put each fish in a `FishSpecies` ScriptableObject (or one JSON/CSV generated from `fish_data.py`):

```csharp
public enum FishRarity { Common, Uncommon, Rare, Epic, Legendary, Mythical }
[CreateAssetMenu] public class FishSpecies : ScriptableObject {
    public int id; public string displayName; public FishRarity rarity; public string family;
    public string[] zones;            // first = preferred zone
    public float spawnWeight;         // see section 5
    public Vector2 lengthCm, weightKg; public float avgLengthCm, avgWeightKg;
    public int baseValue, difficulty;
    public GameObject model;          // Export/Fish/Fish_###_Name.fbx
}
public class CaughtFish { public FishSpecies species; public float lengthCm, weightKg; public string mutation; public int price; }
```

**Spawning a bite.**

```
zone    = highest-priority FishingZone containing the bobber (else OPEN / DEEP by distance to centre)
pool    = species with zone in species.zones
weight  = spawnWeight × (1.5 if zones[0] == zone) × (1 + rod.bonus/100 if rarity >= Rare)
species = weighted_random(pool)
if species.difficulty > rod.power + 8: bite still happens, line snaps during the fight
length, weight = size roll (section 7);  mutation = mutation roll (section 2)
```

**World hooks already in the scene:** `FishingZone_*` empties (zones), `Sea_FishingSpot_1..8` + `Sea_FishSchool_*` (good bite spots inside Open Ocean), `Cave_Pool_FishingSpot` (Teun's Grotto), `Fish_Lighthouse_BeamRig` (beam for night fish at Lighthouse Point), `NPC_Ruben_Spot` (selling).

**Waves and boats.** Fishing reads the water height from the existing `WaterManagement.instance.GetWaveHeight(x, z)` (e.g. to keep the bobber on the surface, the same way `Floater` does). Nothing in the wave code or the boat code needs to change.

**Quests.** `QUESTLINE.md` uses these fish: Q1–Q2 any Common fish, Q5 **Lightfish** (Epic, Lighthouse Point, night), Q7 **Zilverkoning** (Legendary, Teun's Grotto). Rod unlocks in section 4 follow the quest steps.

**Validation (generator asserts):** exactly 122 fish, unique names, 6 rarities (36 Common, 30 Uncommon, 24 Rare, 16 Epic, 10 Legendary, 6 Mythical), every fish has a zone, a price and a size/weight range, every zone has fish, 5 rod tiers.
